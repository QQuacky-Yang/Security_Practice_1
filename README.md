# Security_Practice_1
This is an simulation of "real world security problem." 

## Personal Data Breach Simulation & Defense Platform

## 目標
本專案為一個互動式學習平台，讓使用者理解個資如何因 Web 弱點而被竊取，並學習如何防禦。

## 功能簡介
- 演練 SQL injection、XSS 等實際攻擊
- 練習使用密碼雜湊、防 CSRF、rate-limiting 等防禦技術
- 查看日誌與模擬告警事件
- 安全與不安全版本可互換，用於對照學習

## 技術棧
- Flask + SQLite (可改為 Node.js / Django)
- HTML + JS + Fetch API
- Docker + Docker Compose
